React + TypeScript testing exercises.

## Tasks

### 1. Reverse string

The `reverseString` function is located at:

`src/utills/reverseString.ts`

It accepts a string and returns the string in reverse order.

Tests are located at:

`src/utills/reverseString.test.ts`

### 2. Counter component

The `Counter` component is located at:

`src/components/Counter.tsx`

It:

- accepts a `value` prop;
- displays the initial value in the UI;
- increases the counter by 1 when the button is clicked.

Tests are located at:

`src/components/Counter.test.tsx`.
